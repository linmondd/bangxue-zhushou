# 帮学助手 · 设计说明

## 1. 目标与边界
在用户圈定的范围内，把建行学习（u.ccb.com）专题班课程逐门学完：
- 只驱动**本机已登录浏览器**，通过真实界面操作 + 读取页面状态；
- **不调用平台内部接口、不修改学习记录、不绕过验证/验证码**；
- 完成判定以**刷新后的专题班课程表**为准；
- 范围内自动续班，直到全部完成或遇到需要人工的阻断。

## 2. 架构
```
用户 / Agent
   │  本地控制面板 / CLI（bangxue） / MCP（bangxue-mcp）
   ▼
cli.py ──► runner.py（范围队列）──► monitor.py（班级巡检）──► flow.py（课程流程）
                                                         │
                                                         ▼
                                              drivers/（浏览器驱动）
                                              ├── webbridge.py（WebBridge HTTP）
                                              └── playwright_driver.py（Playwright）
```
- **flow.py**：建课表、进入学习、起播确认、倍速、检查、完成回验、关页。
- **monitor.py**：单班巡检（对账、核进度、关完成、补新课、恢复暂停、错误熔断）。
- **runner.py**：范围队列（当前班 → 整班完成 → 下一个班；范围级锁与暂停）。
- **drivers/**：统一驱动契约，流程层与具体浏览器工具解耦。
- **state.py**：状态文件（原子写、跨平台进程锁）。

## 3. 状态机
### 课程级（每个班的 state.json）
```
queued（未开始）
  └─start→ active（在播）
        ├─ 未到结尾 → active（下一轮继续）
        ├─ 到结尾 → 回验课程表
        │      ├─ 确认 100%/立即回看 → done → 关页
        │      └─ 未确认 → pending（保留页，下轮再核）
        ├─ 标签丢失(notab) → 重新入队 queued
        └─ 阻断 → paused_reason（登录/验证码）或 failed（下架/其它）
```
- `done_open`：已完成但关页失败，下轮重试关闭。
- `failed`：下架/阻断等永久跳过（记录原因）。
- `manual`：scorm/课程包/考试等非视频内容，不自动刷，报告中提示人工。

### 班级级（runner 的 `_scope_state.json`）
```
current（当前班） → 整班课程表全部完成 → done
                  → 报名失败/无课程表/建表失败 → skipped（记录原因）
范围 → 全部核实 done → 完成；含 skipped 或未核实 → 待处理
```
`paused_reason`：范围或班级暂停（user/login/captcha），`bangxue resume` 解除。

## 4. 数据文件
- 单班：`<state.json>`
  - `workshop`、`courses[]`（cid/title/type/prog/act/manual）、`active[]`、`done[]`、`done_open[]`、`failed{}`、`last_ct{}`、`max_concurrent`、`paused_reason`
- 范围：`<state-dir>/_scope_state.json`（done/skipped/current/paused_reason）+ 每班一个 `<wid>.json`。
- 全部为本地文件，UTF-8，原子写（临时文件 + `os.replace`）。

## 5. 关键规则
1. **逐门起播**：打开一门 → 点「我要学习」→ 隔 14 秒确认 `currentTime` 增长 >3s → 才开下一门；失败即停。
2. **完成回验**：播放页 100% 不等于完成；必须刷新课程表看到「100%/立即回看」。
3. **关页顺序**：确认完成 → 关该课页面 → 再开下一门，不堆积。
4. **已完成跳过**：每轮同步课程表（默认 30 分钟缓存），已完成的班/课不再学。
5. **范围续班**：整班完成自动切范围内下一个班。
6. **错误熔断**：登录失效/验证码 → 暂停并报告；下架 → 标记跳过；其余失败有限重试。
7. **不做**：不添加额外课程、不修改进度、不代考。

## 6. 驱动契约
任何浏览器驱动实现以下方法即可接入（见 `drivers/base.py`）：
`list_tabs / open / use / current_url / eval / click / hover / close / bring_to_front / close_all`。
- WebBridge：HTTP 127.0.0.1:10086，按 URL 定位 + `location.href` 回验重试。
- Playwright：持久化用户目录（`bangxue login` 登录一次）或连接调试端口 Chrome。

## 7. 扩展点
- **新浏览器工具**：实现 `drivers/base.py` 契约，加入 `drivers/__init__.py` 注册。
- **新范围**：`bangxue scope --tab <资源库tab名>` 自动生成，或手写 `bangxue_scope.json`。
- **新课程类型**：在 `flow.capture` 标记 `manual`，或扩展 flow 的处理分支。

## 8. 已知限制
- scorm 互动课件、课程包、考试**需要人工**（不自动处理）。
- 课程表若分页，`read_table_rows` 逐页读取，同时核对页码、行变化及可见总数。遇到异常分页或安全上限则报告需处理。平台改版后选择器可能需更新。
- 播放控制（play/mute）仍通过页面播放器实例；倍速优先用平台原生菜单。
- Windows 已做代码兼容（跨平台锁、UTF-8、PowerShell 安装），但未在 Windows 实机验证。
