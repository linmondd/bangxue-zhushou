# 隐私与安全

帮学助手在本机运行。平台地址、登录资料、课程名、进度与日志只保存在用户电脑中。账号和验证码由用户在平台页面自行输入。浏览器登录资料位于本机 `.bangxue/profile`，面板任务位于 `.bangxue/panel`。CLI 和 MCP 按用户指定位置保存状态。

安装时连接软件分发源获取依赖和 Chromium，运行时连接本机浏览器与用户配置的学习平台。控制面板使用本机回环地址和临时访问令牌。

仓库、公开问题、示例、截图和测试只使用模拟内容。实际站点地址、班级名、进度与凭据不应提交到 Git。停止或暂停仅处理能证明由工具创建的页面。用户手动页面或身份不明页面保留并报告。自动化使用应遵守所在平台的规则。
