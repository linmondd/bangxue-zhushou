# 帮学助手 · 隐私与安全

## 一句话
**全部在本机运行；不上传任何数据；不接触你的账号密码；不调用平台内部接口；不修改学习记录。**

## 1. 数据边界
| 项 | 是否涉及 |
|---|---|
| 账号密码 / 短信验证码 | **不接触**。登录由你本人在浏览器里完成 |
| Cookies / 登录态 | 只存在于你本机浏览器（Playwright 的独立用户目录或你日常 Chrome），工具不读取、不导出 |
| 学习记录 | **不修改**。只读页面状态，按平台正常方式播放 |
| 课程名 / 进度 / 课程ID | 仅写入本地状态文件（JSON），用于续跑与对账 |
| 网络请求 | 只连本机浏览器驱动（WebBridge 127.0.0.1 / Playwright 本地进程）与 u.ccb.com 页面本身 |

## 2. 本地会留下什么
- 状态文件：你指定的 `state.json` / `--state-dir` 目录（课程名、进度、状态）。
- 控制面板与学习任务保存在 `~/.bangxue/panel`，其中含本机服务的临时访问链接。面板运行在回环地址，课程名、范围和日志在本机保存。首次安装依赖与浏览器需要连接软件分发源。
- 登录配置目录（仅 Playwright 模式）：`~/.bangxue/profile`（浏览器用户数据，含登录态）。
- 安装目录：`~/.bangxue/venv`（Python 运行环境）。
- 删除方式：
  ```bash
  rm -f 你的状态文件.json
  rm -rf ~/.bangxue        # 连同登录态与运行环境一起删除
  ```

## 3. 操作边界
- 只通过**页面可见控件与页面状态**操作；不注入修改学习记录的脚本。
- 「我要学习」等按钮使用可信点击；倍速使用平台自己的菜单。
- 遇到登录失效、验证码、平台限制会**暂停并报告**，不绕过验证。
- 不代考、不答题、不添加额外课程。

## 4. 分享/上传注意
- 上传到 Git 仓库前，请确认**不包含**：
  - 状态文件（含你的课程进度）
  - `~/.bangxue/profile`（含登录态）
  - 任何账号、手机号、Cookie、Token
- 仓库中只应包含：源码、安装脚本、说明文档、示例范围文件（不含真实账号信息）。

## 5. 合规提示
本工具用于管理你本人已授权的学习任务。请遵守所在单位与平台的使用规则；是否允许自动化播放以平台条款为准。
