# 组件不可用时的 Agent 浏览器流程

遇到帮学助手无法安装、打不开，或浏览器组件、命令行、MCP 无法使用时，使用 Agent 已有的浏览器或电脑操作能力，在用户这台电脑上从正常页面继续。这个流程可以直接执行，也可以作为普通 Prompt 的参考。

## 选择能用的入口

| 当前能力 | 接下来做什么 |
| --- | --- |
| 能操作用户这台电脑上已连接的浏览器 | 先读取用户指定的页面，再从网页可见入口执行。已有可用的登录状态就继续使用。 |
| 能操作用户桌面，浏览器暂未连接 | 通过浏览器界面打开用户提供的地址。平台出现登录或验证时，请用户在浏览器里完成。 |
| 只有独立浏览器环境 | 如该环境支持本人登录及操作，就用用户授权的独立窗口。用户在别处打开的标签和登录态无法自动带入。 |
| 只有聊天、终端或网页搜索，无法操作可用浏览器 | 报告缺少浏览器操作能力，请用户连接浏览器，或提供页面用于只读核对。此时记录已知范围和下一步，任务保持未启动。 |

同一范围已有任务在执行时，先查看其状态。接手前确认上一执行端已经暂停或退出。已有的本地记录可作为定位线索，完成状态仍要回到平台核验。凭据由本人在平台页面输入，操作时使用账号能访问的页面和正常交互控件。平台明确限制操作时，记录限制并暂停。

## 从网页执行

1. **锁定范围。** 从用户指定的网页、当前可见栏目或明确命名的班级开始。先列出班级及可见的报名、进度状态。只读取该栏目范围内的分页或「换一换」结果，按可稳定识别的班级去重。若无法确认列表覆盖完整范围，说明目前只查到哪几页。用户给出的范围清楚时可以继续，有歧义时只确认有歧义的部分。只在授权包括报名、班级也在范围内时办理报名。
2. **建立队列。** 逐班读取完整课表，跳过平台已确认完成的课。默认一次处理一个班、播放一门视频。有部分进度时优先使用页面提供的续播功能，并回读实际播放位置。课程包按可见子课逐门核对，页面明确要求本人处理的互动、考试和验证单独记录。
3. **确认真正起播。** 从课程详情使用平台正常的学习或播放按钮。间隔数秒观察两次，确认播放时间实际增长。只有看到播放器界面确认倍速时，才记录该倍速。若暂停、黑屏或缓冲，可从原入口重进一次再核对。仍未成功就记录原因和课程位置，当前页面未能安全处理时先暂停。
4. **回验完成，再接下一门或下一班。** 视频结束后，在本轮可持续操作时于 1–2 分钟内通过同一班级的课表核对对应课程。确认平台显示 100% 后，才登记该课完成。整班完成需要核对班级身份和完整分页课表，且每项均显示 100% 或平台明确的对应完成状态。部分课表、同名无法区分或平台数据未更新时，保留「未确认」。当前班结束后，从已授权队列中继续下一班；需人工处理的项目保留原因，可安全继续的班级照常推进。
5. **只关能证明归属的页面。** 记下本轮新开页面的稳定标签标识、班级和课程。关页前复核标识和当前页面用途。用户已有的页面、用户已改作他用的页面，以及归属或用途存疑的页面都保留。优先复用一个核对页，切换班级时确认读到的是目标班的课表。

## 汇报与交接

在对话中给出已核验完成、正在播放、排队、待处理和未确认的必要摘要。有本地文件能力时，也可以把摘要保存在仓库之外的本机位置。按班级汇报已确认的课程数量、最后核验时间、卡点和下一步。账号、验证码、完整学习链接及个人记录留在本机，公开仓库只使用示例。

暂停或结束会话前，说明下一次从哪一班、哪一门接起。只有实际存在持续可用的浏览器会话和运行能力，才报告仍在巡检。会话只能执行有限轮次时，报告最后一次核验时间和当前播放状态。恢复时先读目标班的新课表，再从未完成的课程继续。
